## Findings and boundary assessment

**F01 — installed integrated recovery initialization precedes its required authorization.** Production direct Start can supply a genuine S2-qualified identity without final acceptance. QualifiedRecoveryConnection verifies S2 only; RecoveryHost opens/retains the delegated parent; IntegratedRecoveryHost obtains the initial journal writer; M1RecoveryScope durably writes AllocationIntent, releases that writer and spawns O before O's early P2 gate. Native writer acquisition opens/creates `ownership.lock` and takes flock (`Native/JournalFileStorage.cs:164–190`). The initial recovery writer/intent and retained parent are security-relevant initialization effects even though they do not themselves mint a manifest/capability. The normal factory/client gates cover their own callers but do not dominate direct Start. The original plan/P2 clarification supplies the pre-effect requirement; no new owner decision is needed to add refusal.

Source-proven reachability is conditional on the existing unprivileged Linux/S2/closure/delegation prerequisites; it is not a native reproduced exploit. Owner P2 still refuses its writer/domain/staging/manifest transition. No path from these earlier effects to an unauthorized manifest or RELEASE was demonstrated. A default-null `installed` argument on IntegratedRecoveryHost is an additional alternate-entry deficiency: production RecoveryHost supplies it, but the callee currently lacks a refusal for an absent or mismatched retained selection. Recommend one recovery initialization mechanism, separate from owner manifest authority, for S07–S10. See the [handoff](../plans/rc2b-06-b6-alt-b-p4-implementation-handoff.md).

**F02 — B3 constructor omits qualified topology/context refusal.** The real Release constructor creates a journal directory for `QualifiedInstallation=true, IntegratedRecovery=null` without verification. Independent external probes reproduced that effect in Debug and Release. TryCreate already rejects that topology and is the only production constructor caller, so this is a demonstrated unguarded constructor sink, not a demonstrated live factory bypass or arbitrary-user execution exploit. Add local refusal before construction effects; for integrated qualified constructor calls independently require actual protected provider verification before directory effects, or make construction require an equivalent sealed verifier-derived prerequisite. Do not use a Boolean or bare hash as authority. No broad constructor refactoring is necessary.

**Non-integrated qualified B2 needs no new execution-admission guard.** Provider S2 originates in QualifiedRecoveryConnection; recovery and owner establish independent actual-role S2 in QualifiedRecoveryEcho and QualifiedB2Owner respectively. QualifiedB2Owner's first trusted owner S2 is after lifeline establishment, on the authenticated C expectation. Earlier effects establish bounded stop/evidence machinery, not operation/manifest authority. Delegated-parent v2 B2 is already forbidden before parent/journal/domain access in both actors. The accepted v1 delegated control legitimately creates a retained empty domain and must remain callable as legacy. No qualified B2 writer/domain/allocation/staging/HELD path was found, and no earlier B2 effect grants manifest or RELEASE authority. Missing identity, wrong association/identity, missing launch plan or failed confirmation ends positive progression while original stopping/reaping remains. QualifiedB2Owner does not need OwnerAuthorityContext.Qualified merely to echo S2 or honor Stop.

**Legacy and omission distinction.** A false profile flag does not weaken an authenticated v2 installed owner association: transaction classification uses DirectIdentity.InstallationIdentity, not the flag. A genuine v1 request with no installed identity stays within its accepted legacy contract. Deliberately attaching installed identity to v1 refuses. There is no production path that produces a null owner context in Run: it supplies either verified Qualified or LegacyContext. Private-method reflection with malformed legacy/null inputs is not production reachability. Validation has no production factory. Do not infer installed authority from matching filenames, `internal`, friend access or the disabled public facade.

No **DESIGN DECISION REQUIRED** sink remained: F01 is covered by the existing pre-effect requirement and F02 by existing qualified-topology/refusal rules. P3's accepted O1/O2 are not reopened. No current recovery-only manifest or RELEASE authority was found.
