Basis: G1 independent review `docs/reviews/gagamba-linux-m1-g1-review.md`

Corrections applied, all inside WP01 boundaries (no new production
surface; `ReferenceEncoder.cs` is test-only):

- G1-01: all canonical sorts use `Utf8BytewiseComparer` (strict UTF-8
  bytewise, never UTF-16 ordinal). Proven by `NonAsciiKeysSortByUtf8Bytes`,
  `SupplementaryUnicodeSortsByUtf8Bytes`, `StrictUtf8RejectsLoneSurrogates`
  and the reference-encoder non-ASCII vector, whose hand-derived order
  (`caf\u00E9 < ee < ipc < user < U+E000 < U+10000`) fails under ordinal
  comparison (ordinal would place U+10000 before U+E000).
- G1-02: `AuthorityManifest` carries `ExecutableMountPolicy`
  (tool-executable enforced true) and `NetworkQualification` pinned to
  PendingQualification; `ResourceManifest` carries `InodeQualification`
  pinned to PendingQualification, `CoreDumpPolicy` (core-disabled
  enforced true; non-hermetic resolve rejected) and
  `OwnerAllocationLimits`. Establishment is represented by
  `EstablishedManifest` (Absent singleton / Unknown / Observed) and
  cleanup by validated `CleanupReport` (Confirmed requires all-known,
  Failed requires at least one known).
- G1-03: `TryCommitRelease` rechecks the stop gate after the durable
  intent write; a stop that wins first yields StoppedFirst with
  MayHaveExecuted (`ReentrantStopDuringIntentWriteWins`).
- G1-04: an identical duplicate release returns the recorded decision
  without re-driving the transport; a conflicting identity or digest is
  refused (`CommitSuccessWritesIntentBeforeSend` updated to the retained-
  decision contract, `DuplicateReleaseReturnsRetainedDecision`).
- G1-05: recorded observations never regress — duplicates are idempotent,
  conflicts carry new `InvariantViolation.Conflict = 8` (existing numbers
  unchanged, still pinned by `EnumNumbersArePinned`); terminal collections
  are immutable snapshots (`TerminalCollectionsAreImmutable`,
  `RecordedRootExitCannotBeOverwritten`,
  `KnownRootCannotRegressToUnknown`,
  `OverflowStopThenCleanExitYieldsStoppedWithRootPreserved`).
- G1-06: the terminal observation retains identity, manifest, digest,
  release disposition, stop causes and monotonic sequence after
  invalidation; helper/capture observations are admitted pre-release and
  during pre-release teardown (`TerminalRetainsMetadataAfterInvalidation`,
  `HelperAndCaptureObservedPreRelease`,
  `HelperAndCaptureObservedDuringPreReleaseTeardown`,
  `UnsatisfiedPrerequisitesRefused`).
- G1-07: in-repo independent reference encoder
  (`tests/.../Contracts/ReferenceEncoder.cs`, own primitives and own
  bytewise comparer, never calls `ManifestCodec`) agrees byte-for-byte
  with production on the sample and on a permuted non-ASCII manifest, and
  digests agree (`ReferenceEncoderMatchesProductionOnSample`,
  `ReferenceEncoderMatchesProductionOnPermutedNonAscii`).
