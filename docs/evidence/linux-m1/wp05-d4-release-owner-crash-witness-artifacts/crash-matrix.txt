# D4 crash boundary and no-resend matrix

Source HEAD for evidence: `de1ee93fdfa9cc29cf82a79f6e6dac9bfea7d753`.
All cases used a fresh test-only owner process. Replacement processes received
only the journal path (and source path for the test-only capability
diagnostic), never a capability, writer, HeldExecution or FD4 writer.

`TestTransportAttempt` event. No case observed a second production-coordinator
exit 0. In D4-3/D4-4 the owner died before reading the coordinator result;
acceptance is therefore recorded as unknown, not inferred from the journal or
the write return.
