Date: 2026-11-09 (Asia/Manila)

The fixtures are hand-written canonical CJSON-1 templates for the accepted B2/no-release/pre chain and the B3/release/post chain. They are **test-only, non-authoritative fixtures, not approved catalog instances**. Digests were computed with the platform SHA-256 primitive over the exact fixture bytes (UTF-8, no BOM, no trailing newline) and re-verified with `Get-FileHash`.

## Construction and demonstration method

1. `fixtures/generate-fixtures.ps1` builds each artifact from hand-written canonical JSON templates using string composition only (no P1 encoder, no library serializer); the F/S/K templates embed the recomputed upstream digests, exercising the accepted `M → F → S → K` dependency direction.
2. The script writes the exact bytes (UTF-8 no BOM, no trailing newline) and a digest manifest.
3. `FrozenContractTests` hard-codes byte-identical fixture strings and the independently computed digest vectors, and asserts successful chain verification plus exact hash values; expected values are never derived by calling the code under test.

## Reproduction

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File docs/reviews/rc2b-06-b6-alt-b-slice-e-02-p1-evidence/fixtures/generate-fixtures.ps1
Get-ChildItem docs/reviews/rc2b-06-b6-alt-b-slice-e-02-p1-evidence/fixtures -Recurse -File -Include *.json |
  ForEach-Object { "$($_.Name) $((Get-FileHash $_.FullName -Algorithm SHA256).Hash.ToLower())" }
```
