## Decisions needed to freeze the implementation interface

1. Pin repository carrier, executable identity representation and exact closure/readback rules for fixed L, C and D, including how the reviewer will select the actual inspected artifacts. The accepted path, catalog hash fields and fd/packet contract establish design requirements. No reviewed production carrier, native build/package binding, exact operator argument schema and resolved installed role/closure measurement interface were located for this E-5 package.
2. Freeze protected input ownership and the narrow handoff to and from L/C across E-5/E-6. Decide whether E-5 delivers an inert managed seam or a separately commissioned native component. Define the expectations' independently owned representations, lifetime boundaries, refusal types and permitted dependency direction before any caller is authorized. A managed seam can model results of platform checks using test-only operands.
3. Bind D's later launch/transport/dispatch seam to the accepted C-to-D contract and E-7 exact closure. Allocate production files and tests only after this allocation and E5-01–E5-03 are resolved. The current acceptance neither selects the older v2 driver proposal nor establishes a direct L-to-D interface.
