# First E-1 production consumer prerequisite

**Not selected or authorized by this assessment.** Recommended candidate for the separate decision: original C's prevalidation integrity adapter before B2 consumption and before B3 provider/operation construction, owned by E-6. The accepted [carrier reservation](../rc2b-06-b6-alt-b-slice-e-05-design-owner-01-evidence/launcher.md) is `src/Gagamba.Validation.Controller/Gagamba.Validation.Controller.csproj`; it is not yet an implemented or qualified emitted artifact. C already needs to bind its loaded provider and separately reviewed controller closure before HELLO and to recheck its original selection before B2. The decision must distinguish these two observation times and forbid re-adoption. This recommendation identifies a concrete consumer for review, not a new callable API or activation.

E-5's L performs its own full integrity and host checks through native code; it must not import a managed snapshot as its provenance. Original R and O each need later role-specific E-1 use before their local effects. A first-C decision does not automatically authorize those consumers. The native L contract and C consumer contract must agree on comparison inputs without delegating one actor's verification to another.

Sources: [E-1 acceptance](../rc2b-06-b6-alt-b-slice-e-01-owner-acceptance-01.md); [F-01 closure §9](../rc2b-06-b6-alt-b-slice-e-01-f01-owner-acceptance-01.md); [F-02 closure §11](../rc2b-06-b6-alt-b-slice-e-01-f02-parity-owner-acceptance-01.md); [E-5 allocation](../rc2b-06-b6-alt-b-slice-e-05-design-owner-01-evidence/responsibilities.md).

**BB-02 is a different Option A.** E-3's Option A isolates the new v3-pre codec from affected legacy integrated-v2 null-member behavior. Its legacy bootstrap nonconformance remains open; any affected v2 reuse/remediation needs explicit reassessment and controls. E-1 Option A concerns shared verifier core consolidation. Neither option closes the other. Postvalidation uses accepted v2 shapes, so the future integrated post path must explicitly account for BB-02 rather than assuming isolated pre acceptance qualifies it.

Composite Q-E1 has accepted E-2 schema provenance, adopted E-3 layout and E-4 wire/handoff subsets. It remains open for live context and independent owner release correlation/atomic enforcement. Selecting an E-1 consumer does not close Q-E1, BB-02 or native evidence.

A separate consumer prerequisite commission is required **before E-6 implementation that introduces any production projection consumer**. It need not block pure production-unreachable P1 release preparation, which neither calls E-1 nor accepts its objects. Recommend handling EC01–08 in one first-consumer design/authorization decision tied to the native handoff contract, avoiding separate commissions for each parity finding.
