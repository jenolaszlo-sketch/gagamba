All managed expectations here are planned for a separately authorized exact candidate. Independently bind the committed normative sources and fixture hashes before executing. A different Codex task uninvolved in E-4 implementation must record its actual task identity, corroborate independence, and stop before executing qualification if independence fails. Produce raw case outcomes, test-discovery/case accounting, commands, DLL hashes, exact commit/tree and checksum manifests. Owner acceptance is a subsequent separate decision.
