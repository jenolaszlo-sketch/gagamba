## Common validation sideband frame GAVA1

New authority sockets are dedicated AF_UNIX SOCK_SEQPACKET|SOCK_CLOEXEC|SOCK_NONBLOCK, never generic M1OP/GID1 dispatch. Exactly 64-byte header: ASCII `GAVA` bytes0..3, u16 LE version1 @4, type u8 @6, sender role u8 @7 (L=1,C=2,R=3,O=4), payloadLength u32 LE @8, sequence u32 LE @12, session GUID16 @16, execution GUID16 @32, lease GUID16 @48. GUID byte order is existing .NET TryWriteBytes order, nonempty. Per-direction sequence begins1 and advances only on one fully valid record; no wrap, replay, reconnect or resync. Maximum payload128 bytes except the separately specified admin challenge; exact lengths below override the bound. No trailing bytes, unknown flags, type or role.

All sideband receivers enable SO_PASSCRED before the sender can send. Each record requires exactly one SCM_CREDENTIALS of size12, matching actual expected pinned sender/UID/GID; zero user-provided credential cmsgs are sent. Rights count/order must equal the table; no other cmsgs, truncation or unknown ancillary data. Kernel pidfd peer checks apply to freshly connected endpoints; inherited socketpairs use per-record credentials and original spawn custody because SO_PEERCRED reports the creator's identity. Missing kernel features refuse, never degrade to claimed IDs. [Linux Unix credential/rights semantics](https://man7.org/linux/man-pages/man7/unix.7.html).

| Type / sender -> recipient | Exact payload and rights | Authentication, ownership and phase |
|---|---|---|
| 1 HELLO C->L | catalogHash32 + generation32, 64 bytes; zero rights | Inherited L-C pair; original C child, non-root actual credentials. Header establishes C-generated GUIDs once before issuance. |
| 2 OFFER L->C | capabilityHash32 + catalogHash32,64 bytes; exactly two rights in order read-only sealed memfd, original L pidfd | Same pair, SCM UID/GID0 from original live L; C previously pinned its real parent L before HELLO. Capability C identity/GUIDs must match C itself. Root provenance is this authenticated handoff, not memfd metadata alone. |
| 3 DROP-COMMIT L->C | capabilityHash32,32 bytes; zero rights | Same L pin, actual non-root accepted credentials and verified permanent drop, after OFFER; C consumes once, never on OFFER alone. |
| 4 INIT C->R, R->O | capabilityHash32 + catalogHash32,64 bytes; zero rights | On distinct spawn-local sideband; memfd and original L pidfd inherited through fd allowlist, not named in payload. Parent actual credentials and original spawn association. Must precede any side effect beyond startup/stop service. |
| 5 CONTEXT-ACK R->C, O->R | capabilityHash32,32 bytes; zero rights | One response after local grant/catalog/loaded checks and binding; does not replace existing installation echo/Ready. |
| 6 DIRECT-CONTEXT C->O | capabilityHash32 + catalogHash32,64 bytes; zero rights | Separate fresh direct sideband endpoint authenticated with the **same original C/O pins** obtained by S3. O compares inherited context. Before positive installed evidence can authorize staging. |
| 7 DIRECT-ACK O->C | capabilityHash32,32 bytes; zero rights | Original O actual credentials, once; cannot be forwarded by R. |
| 8 TERMINAL C->L | capabilityHash32 + result u8 (1 Confirmed,2 Unknown,3 Refused) + seven zero bytes,40 bytes; zero rights | Original C; diagnostic closure/lifetime coordination only. Does not authorize cleanup or erase Unknown. |

L-C directions are C HELLO1 then TERMINAL2, L OFFER1 then DROP-COMMIT2. Parent-child sidebands are INIT1/ACK1; direct C-O sideband CONTEXT1/ACK1. Every endpoint is one-shot and cannot dispatch release/control. Unexpected record/descriptor terminates positive progression and closes that authority path, invokes original existing stop obligation, retains original references needed to reap.

The extra direct context sideband uses abstract address zero-byte plus ASCII `gagamba.va.` plus session32; exact address length, no trailing NUL. C creates listener before R spawn, backlog1, accept once then close listener, wrong first connector refuses. O connects only after its accepted bootstrap supplies original C pin. Both ends use SO_PEERPIDFD/SO_PEERCRED and per-record SCM_CREDENTIALS against same original pins, no transferred endpoint. C sends6 then shutdown(SHUT_WR); O requires one exact frame and genuine drained peer half-close, sends7 then half-closes; C requires same. Empty/surplus packets refuse. This mirrors S3's evidence proof without widening its message allowlist. Direct sideband contains only context, never installation echo or lifecycle traffic.
