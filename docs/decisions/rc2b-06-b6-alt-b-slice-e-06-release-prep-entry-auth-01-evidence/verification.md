## Required producer sensitivity

Create disposable, noncanonical variants, hash their source and outputs and run a passing valid control followed by the named failing security witness against each meaningful variant in both configurations. Preserve exact altered predicate, expected outcome and actual test/suite failure. A build break, fixture failure, unsupported host, unrelated assertion, or skipped negative supplies no detection. On canonical candidate bytes both controls must behave as specified.

| Mutation family | Required detection |
|---|---|
| Omit comparison of each of the four IDs and each of the five digests, independently | The single-operand mutation for that slot detects each omission. |
| Remove case or phase comparison independently, or bypass required original expectation | Detect ordinal mismatch, phase mismatch or incomplete original binding, respectively. |
| Remove the topology check, indexed sequence check, release-index check, or either of the K/F flags | Exact wrong-case or wrong-slot negative fails. Exercise a valid no-release projection with otherwise complete hash values and test with an actually divergent step/index rather than relying on hash differences. |
| Remove digest presence, exact length, or digest comparison | Missing/wrong-width and R02 witnesses detect the respective omission. |
| Alter the domain, separator, field order, index endian, GUID endian or width or hash input extent | Full preimage and fixed digest witnesses detect each altered representation. |
| Substitute borrowed backing for an owned result or let a later call mutate prior output | Defensive-ownership witness detects the alias or later overwrite. |
| Add an incoming production-origin reference to a known helper member in a disposable scan control | Scanner identifies exact method and reference. Compile-and-scan only. The control does not enter the released candidate or execute any production caller. |

If another independent check would incidentally reject the same mutant, select a negative that distinguishes the omitted predicate or exercise the relevant intermediate branch through a disposable test harness. Report redundant checks or an undetectable omission explicitly and resolve any missing detection of required behavior before producer handoff. Keep oracle generation separate from the implementation under test.
