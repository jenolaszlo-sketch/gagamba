# D2 — responsibility and handoff allocation

This is a design allocation, not acceptance of any unimplemented operation. E-5 is split into the initial managed model and a separately authorized later native L/C custody adapter. E-6 is accountable for the complete atomic dependency set even where another slice produces an input. Implementation order does not permit partial exposure. Sources: [E-1 sequence](../rc2b-06-b6-alt-b-slice-e-01-entry-owner-decision-01.md) §9, [plan](../../plans/rc2b-06-b6-integrated-start-authority-impl-01.md) §§3.5–3.6, [D1](../rc2b-06-b6-alt-b-slice-e-02-d1.md) §§5–13, [E-2 closure](../rc2b-06-b6-alt-b-slice-e-02-closure-owner-01.md) §§5–7, and the F02 sources identified in [provenance](provenance.md).

## Frozen cross-slice handoffs

1. **Administration → L:** E-6's constrained transaction exposes exact protected selection and independently designated V/W/A evidence; later E-5 L opens its own objects and retains original identities. No injectable “trusted reader” or Boolean approval enters production. L cannot create P or substitute a root. A's live response remains separate from P eligibility.
2. **E-5 → E-6:** native adapter must eventually provide retained original L/C resources, immutable selected bytes/identities, actual provenance/peer/drop/read observations and their failure/cleanup state, all bound to one host/boot/session/execution/lease and original deadlines. E-6 checks these at its own barriers and exclusively owns positive B1/B2 integration and atomic activation. The initial managed `ValidationCustodyModelSnapshot` is expressly **not this production handoff type** and has no conversion to it. A later native contract authorization must define nonforgeable constructors/resource types and actual wire 1–3 against the already accepted F02 format; no synthetic import path is allowed.
3. **E-6 → E-7:** C retains K/S, exact case, original IDs and D executable/closure expectation. Only C can start its one D and provide compiled `--case <verified-caseId> --catalog <Hk> --session <original-sessionN>` plus fd103. E-7 cannot supply expected policy to C, receive grant/L pidfd, call the arbiter, or bypass E-6. No direct L-to-D authority edge exists.
4. **All producers → Slice N:** exact artifacts, independent expected values, named native claims and real cleanup oracles. Portable model/codec successes are test evidence, not replacement OS observations. Slice N produces qualification, not permission to publish or activate.

E-6 owns the implementation gate for the first E-1 consumer if it proposes one; the existing **unassigned consumer itself remains unselected** until a separate consumer decision. Repository/owner preservation is accountable for the external durability/ancestry follow-up; this assignment neither archives the package nor proves its history. These are explicit follow-up responsibilities, not closed obligations.
