# Custody model, lifecycle and deterministic refusal

Sources: F02 Mechanism B issuance/consumption, original process and descriptor custody; [entry lifecycle reconstruction](../rc2b-06-b6-alt-b-slice-e-05-entry-owner-01-evidence/custody-and-lifecycle.md); [E-3/E-4 structural contracts](../rc2b-06-b6-alt-b-slice-e-05-entry-owner-01-evidence/contract-and-interfaces.md); [D3 types](contract.md). All states below end in `Model` precisely because none establishes real protected custody.

## Validation ordering

`TryCreate` sets out model null first. It checks: (1) operand shapes/enums, pre scope, independent expected binding completeness, facts' enum values and creation time shape (Context); (2) stopObserved (Stopped); (3) current deadline expiry (Expired); (4) all observed Binding fields equal independently retained expected Binding (Comparison); (5) mandatory facts (Evidence); then snapshots inputs and creates PendingModel. `nowNs < 0` or `AdmitBeforeNs <= 0` or `SessionEndNs < AdmitBeforeNs` is Context; a well-formed now at/after AdmitBeforeNs is Expired. No factory can return a partially valid model.

`Advance` sets out snapshot null before acquiring its private gate. Under that gate: (1) disposed/Closed instance or wrong next event returns Transition; (2) malformed operand, undefined enum, negative time or backward time returns Context; (3) observed stop returns Stopped; (4) applicable deadline expiry returns Expired; (5) every Binding field comparison against the original retained expectation returns Comparison on first mismatch; (6) mandatory/stage-specific premise checks return Evidence; (7) commit exactly one next state and last-time value, then copy a diagnostic snapshot. Wrong transition has priority over other invalid operands on Advance. Within comparisons use the field order printed in D3's Binding row; within facts use the row order below. Return codes are stable; no per-field exception text or secret-bearing dynamic diagnostic is exposed.

Any failed Advance, including duplicate or malformed attempt, sets state Closed and clears retained Binding/expected data before releasing the gate. No success snapshot, rollback, retry, resurrect/rebind or replacement original follows. An already returned snapshot remains inert diagnostic data and cannot be revoked or reused as authority. Closed/disposed calls always return Transition and null. `Dispose` is idempotent, locks the same gate, sets Closed and releases managed references; it returns no success/proof and performs no I/O. No public State accessor is needed; tests observe subsequent refusal.

## Allowed transitions and stage evidence

At every create/advance require `ProtectedInputs`, `Provenance`, `ApprovalCurrent`, `OriginalAssociation`, `LiveOriginals` each Consistent, subject to the withdrawal rule below. Unknown or Contradictory always refuses for required facts. For facts not yet due, require Unknown; supplying premature Consistent/Contradictory is Evidence, not early progress. Once due, facts remain Consistent through subsequent events. CleanupConfirmed is Unknown until Complete, then Consistent. This closes the input domain and prevents ignored surplus “proof”.

| Pre-state / operation | Required stage fact added | Post-state / observable success |
|---|---|---|
| No instance / TryCreate | All six stage facts FreshAuthorization, IssuanceCommitted, OfferValidated, PermanentDrop, ConsumptionCommitted, CleanupConfirmed are Unknown | PendingModel; original expected L/C, IDs, catalog/approval and deadlines retained, no resource or authority acquired |
| PendingModel / ObserveIssue | FreshAuthorization and IssuanceCommitted Consistent | IssuedModel snapshot; models observed B1 only, performs no issue/lock/marker operation |
| IssuedModel / ObserveOffer | OfferValidated Consistent | OfferedModel snapshot; models original matching OFFER, never consumption |
| OfferedModel / ObserveDrop | PermanentDrop Consistent | DroppedModel snapshot; supplied original-L permanent-drop evidence agrees, no privilege call |
| DroppedModel / ObserveConsume | ConsumptionCommitted Consistent | ConsumedModel snapshot; models B2 observed on same originals; no live context or action authority |
| ConsumedModel / Complete | CleanupConfirmed Consistent | Closed snapshot made before releasing retained references; structural terminal evidence only |

FreshAuthorization binds the same challenge/original tuple by stipulation in this bounded model; no challenge bytes/parser or replay store exists here. The model's one-way per-instance sequence is its only replay guarantee. A new model with copied synthetic operands can be constructed; this is intentional testability and must never be claimed as global invocation uniqueness or authentic B1/B2 consumption. Real challenge nonces/hash, one-response lock, original process pin and spent invocation are E-6/native gates.

**Withdrawal boundary:** `ApprovalCurrent` means eligibility/current protected approval at TryCreate and ObserveIssue. After ObserveIssue it means consistency of the original issuance-bound approval evidence, not continued publication of P. Withdrawal after committed B1 does not revoke the admitted invocation or require a new A response. The Evidence type cannot express live withdrawal timing; tests represent withdrawal-before-B1 as not Consistent and withdrawal-after-B1 by retaining original evidence. No new pre-RELEASE administrative revocation rule is created. Other original-input comparisons continue to refer to the retained selection; actor-local generation checks at later live barriers remain E-6 obligations.

## Refusal matrix

| Invalid input/transition | Exact model outcome (after earlier-priority checks) | Existing semantics and downstream obligation |
|---|---|---|
| Missing expectations/evidence/binding, invalid digest size/IDs/case/time shape, non-null pre qualification pair, post/v2/unknown topology or enum | Context; null output; failed Advance closes | Mirrors the meaning of E-3/E-4 Context without altering their enum or wire codes. Missing state never defaults to trusted. |
| Wrong L executable/closure or C/D executable/closure, jointly changed suspect inputs, wrong Hk/Hm/Hf/Hs/Hr/Hw/Hp/artifact/capability | Comparison; null output; closes | Compare all fields with separately held expected values, not only with each other. L identity never taken from K. Actual closure missing blocks native use. |
| Wrong original L/C association labels, swapped originals, host/boot/selection/session/execution/lease/case/deadline mismatch | Comparison; null output; closes | Bare matching IDs do not establish authentic process custody. Original association facts also mandatory. |
| Missing/contradictory protected acquisition, provenance, approval, live original association, fresh A, issue/drop/offer/consume or cleanup proof | Evidence; null output; closes | Operational unknown/unavailable always refuses. This new local category is needed because E-4 framing codes do not encode lifecycle evidence. It has no operational wire meaning. |
| Stale/inapplicable approval | Comparison for changed binding; Evidence for unknown/contradictory current eligibility at issue; Expired for the expired original deadline | No automatic replacement approval. Post-B1 withdrawal follows the explicit rule above. |
| OFFER without prior issue; DROP without OFFER; consume without DROP; repeated event; complete too early; any event after terminal/dispose; undefined event | Transition; null output; closes | No one-use reset, retry or promotion. Undefined event is classified here before operand checks. |
| stopObserved on otherwise valid pending transition | Stopped; null output; closes | Supplied observation wins before any new successful progression. Real stop/reap service stays available independently. |
| nowNs at/after applicable deadline | Expired; null output; closes | Equality expires; original bounds never extend. Backward time is Context. |
| Malformed E-2/E-3/E-4 input in composition tests | Original verifier refusal and null/failed output; **do not invoke model with successful premise** | Preserve `ValidationPreRefusal`, `Gava1Refusal`, E-2 bool/diagnostic results. No competing framing/parser implementation. |

There is no native cleanup API in the model. Failed model Complete with missing cleanup evidence is refusal, never Confirmed. Actual runtime terminal result remains the accepted Confirmed/Unknown/Refused vocabulary; incomplete native cleanup is Unknown and must keep original stop/reap duties. A model refusal cannot claim it closed a real descriptor or reaped a process.

## Resource, concurrency, exception and cancellation contract

The model owns copies of values only. Native sender/receiver ownership is preserved as a future adapter requirement: borrowing original handles cannot divest sender custody; successful rights send queues duplicates; receiver collects and closes every invalid delivered copy, never a payload-selected integer; validated copies transfer to one scoped owner; originals needed for stopping survive failure. Native fd100/101/102 stay with C/R/O as prescribed, never D/T; D only has fd103 from C. Actual queued-right destruction, close/reap and procfs evidence require Slice N.

One private gate linearizes Advance and Dispose. Two contenders for the same next transition can yield at most one success; the later invalid event closes the model. If stop and progress calls contend, the gate order defines the model observation order; an earlier committed success is not retroactively revoked. A call that observes stop under its transaction cannot succeed. No claim of external cancellation atomicity is made. Test with deterministic barriers, not sleeps; Dispose-first must always make later Advance refuse. No await, external callback, filesystem I/O or blocking wait under this gate.

There is no CancellationToken/async surface: `stopObserved` is a deterministic observation operand. The caller owns prompt external stop servicing in any future adapter. Invalid supported operands yield codes, not exceptions. No throwing getters/delegates are accepted. Unexpected implementation exceptions may propagate, but an Advance must close and clear its model in failure cleanup and leave out snapshot null; TryCreate must leave out model null. Allocation/resource exhaustion is not promised recoverable. Callers must never translate any exception into success. No exceptions may manufacture a snapshot or authority result.

Managed tests can prove comparison completeness, deterministic codes, transition/lifetime behavior within one instance, deadline/stop observation ordering, defensive ownership and zero code paths to effects. They cannot prove independently authentic provenance, actual fixed executable closure, real process identity, protected custody, drop, packet/descriptor properties, real cancellation responsiveness, native cleanup, administrator designation or permission to execute.
