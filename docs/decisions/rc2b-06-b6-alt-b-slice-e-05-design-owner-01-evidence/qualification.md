## Exact compiled isolation controls

At producer and independent gates, inventory all compiled production entry assemblies (M1, Owner, Recovery, Runtime and any currently shipped/fixture C carriers), dependency outputs, actual test-loaded copies and any publish outputs used as evidence. Record raw SHA-256, target/configuration and source revision. Enumerate all methods, constructors, type/signature/generic tokens, call/callvirt/newobj, delegate/ldftn references, static initialization and supported reflection-name strings involving the new model, E-1 projection, E-2 verifiers and E-3/E-4 codecs. Supplement with source search for reflection, dynamic lookup/registration and entry-point dispatch; state unsupported analysis explicitly.

Allowed production references are **only** the two new files' references to their own model types, ordinary BCL values/array/locking and existing `ValidationPreContext`, `ValidationPreTopology`, `Gava1Ids` values. There must be zero incoming production references to model callable methods or model operands outside those two files, zero new calls to E-1/E-2/E-3/E-4 callable verification surfaces, zero outbound protected effects/native imports/authority factories, zero public model types and zero conversion from snapshots to authority. Tests contain the expected positive references to prove scanner sensitivity. Known existing codec test calls and ordinary production calls must be detected, not silently filtered. A disposable added production-to-model call must fail the isolation oracle. Direct-call absence alone is insufficient for an exhaustive claim; combine enumerated metadata and manual dynamic-path analysis without claiming undecidable reachability proof.

The anticipated initial call graph is test → model, and separately test → unchanged codecs → test adaptation → model; model → existing inert value types/BCL only. There is no production entry → model, model → codec function, model → native custody, or snapshot → authority edge. Any such edge is out of scope and requires a new authorization rather than a waiver under “internal”.
