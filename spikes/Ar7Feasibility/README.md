# AR-7 disposable feasibility probes

P01 is new probe code, not a production provider or historical experiment.
`run-p01.ps1` builds with MSVC 14.51 / public Windows SDK 10.0.26100.0 and
runs outside the Codex filesystem sandbox so its restrictions cannot supply the
observed authority denial. No elevated token is accepted by the native host.

The native executable is statically linked to the C runtime. Three workers run
sequentially: ordinary user (0), zero-capability AppContainer (1), and LPAC (2).
The controller externally queries each suspended token before release.
Creation-time Job association places every worker in both an outer cleanup Job
and its candidate Job. Broker children belong to the outer Job alone.

Synthetic resources use explicit, logged DACLs. The eight pipes comprise two
name variants (global and LOCAL), each with Everyone, AAP, ARAP or exact package
permissions. Exact-package endpoints deliberately test candidate reachability;
they are positive controls, not ungranted profile authority. The ordinary
AppContainer's AAP behavior is a comparison, not an LPAC acceptance condition.
The controller validates nonce plus actual client PID before launching its
finite child. Endpoint effects and Job membership are observed by the controller.

The targets execute only this bounded fixture: seven reads, two writes and eight
pipe attempts, no arbitrary target code. At most 24 broker children are created,
each living 200 ms; each worker has a 10-second self-watchdog, the controller has
a 12-second per-worker deadline, and PowerShell has an independent 30-second
host watchdog. Jobs add kill-on-close, not resource or IPC restrictions. These
source bounds do not qualify hostile-workload resource limits (P04).

Exit zero means harness execution/cleanup finished, not candidate success.
Interpret the worker results, endpoint receipts, effects, tokens and cleanup
separately. Missing positive controls are inconclusive. Every unsupported leg is
reported explicitly; no real broker or service is activated here.

All fixture paths and profile identities are generated by the trusted script
before release. Cleanup stops Jobs and queries emptiness before removing only
listed files/directories; it does not traverse target-supplied paths. On cleanup
uncertainty, preserve fixture identities and stop. Raw output and binaries are
ignored under `artifacts/ar7/P01`; durable evidence retains observations and
source/binary hashes separately. No AR-6 qualification seal applies to this code.
